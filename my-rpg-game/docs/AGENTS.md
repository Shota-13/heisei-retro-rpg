# AGENTS.md — AIコーディングツール向けの入口

このファイルは**入口(目次)だけ**を持つ。ルールの本文は `docs/` にある。

## 作業を始める前に必ず読む

| 順 | ファイル | 内容 |
|---|---|---|
| 1 | `docs/DECISIONS.md` | 設計の**確定事項**。最優先 |
| 2 | `docs/CODING_RULES.md` | 作業ルール(スコープ、設計、検証、禁止事項)、層の依存方向、用語対応表 |
| 3 | `docs/READABLE_CODE.md` | 読みやすいコードの書き方 |
| 参考 | `docs/AI_PROMPT.md` | プロジェクト概要・ロードマップ・今回の依頼 |
| 参考 | `docs/ASSETS.md` | 素材の出典(素材追加時に追記) |

## 優先順位(矛盾したとき)

`DECISIONS.md` > `CODING_RULES.md` > `READABLE_CODE.md` > `AI_PROMPT.md`

矛盾や不明点は、自分で判断せず**質問する**。

## 最低限の3原則

1. 依頼された範囲だけを変更する。無関係なコードは触らない
2. 確定事項を変える提案は、理由を添えて確認を取ってから
3. 実行していないものは「未検証」と明記する
