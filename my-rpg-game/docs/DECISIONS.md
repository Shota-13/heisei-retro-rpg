# DECISIONS.md — 設計決定記録

最終更新: 2026-10-15
方針: ここに書かれた項目は「確定」。変更する場合は理由を添えて、このファイルを更新してから実装する。

---

## 1. 基盤・環境

| 項目 | 決定 |
|---|---|
| エンジン | Phaser 3 + TypeScript(strict) + Vite |
| マップ作成 | Tiled(JSON出力) |
| ホスティング | Cloudflare(GitHub連携で自動デプロイ) |
| 配信 | まず Web / PWA。将来 Capacitor でアプリ化 |
| データ保持 | 端末内のみ(サーバー・DBなし) |
| Phaserのバージョン | 3系で固定(`package.json` で完全固定すること) ※要確認 |

## 2. 画面・解像度

| 項目 | 決定 |
|---|---|
| 内部(論理)解像度 | **320×240(4:3)** |
| 倍率 | `SCALE` を1か所の定数で管理。初期値3(キャンバス 960×720)。2〜4で調整可能にする。コード内に 960 などを直書きしない |
| 通常シーン | カメラを `SCALE` 倍ズームしてドット絵を描画(ピクセルアート設定: nearest) |
| 高画質シーン | ズーム1倍で高精細画像を描画。**背景画像は4倍(1280×960相当)で制作し、必要なら縮小して使う** |
| タイル | 16×16 |
| キャラの枠 | **全キャラ 16×24 に統一**(主人公・仲間・NPC)。ボスなど大型は個別サイズの専用絵 |
| 画面向き | ゲーム画面は横長(4:3)。**スマホは縦持ちで、上に画面・下に操作盤** |
| 操作盤 | HTML/CSSの部品(十字キー / A / B / MENU / SELECT)を画面下に配置。PCでは非表示。詳細は「3. 移動・操作」。横持ちは後回し(現状は画面に重ねて表示する暫定CSSのみ) |

## 3. 移動・操作

| 項目 | 決定 |
|---|---|
| 移動方式 | 8方向の自由移動 + Arcade Physics(斜めは正規化) |
| 当たり判定 | キャラは足元の小さい矩形のみ |
| 描画順 | Y座標でソート(`depth = y`) |
| 入力 | `InputSystem` でアクション化(`up/down/left/right/confirm/cancel/menu/select/dash`)。キーボード・HTML操作盤・ゲームパッドは入力源(`InputSource`)として追加 |

### ボタン構成(確定)

| ボタン | アクション | 役割 |
|---|---|---|
| 十字キー | `up/down/left/right` | 8方向移動、メニューのカーソル移動 |
| A | `confirm` | 決定、話す・調べる(**Undertale方式: 向いている先を直接調べる**)、会話送り |
| B | `cancel` | キャンセル、メニューを閉じる、会話の早送り |
| MENU(START相当) | `menu` | フィールドでメニューを開く |
| SELECT | `select` | **予約**(ボタンは置くが機能は未割り当て。候補: 先頭キャラ入替、マップ、ヘルプ) |
| (ボタンなし) | `dash` | **予約**(アクション名だけ確保。キーボードはShift。実装は必要になった時点で判断) |

- L/R、X/Y は置かない(必要になったらHTMLボタンを足し、`InputSystem` にアクションを追加するだけで済む構造にしてある)
- MOTHER3の正確なボタン割り当ては未確認。上表は「MOTHER2/3・Undertale風の操作感」を基準にした設計案で、実機で触りながら調整する
- キーボード: 移動=矢印/WASD、confirm=Z/Enter/Space、cancel=X/Esc/Backspace、menu=C、select=V、dash=Shift

### 十字キー(タッチ)の判定方式(確定)

- 十字キーの中心から指までの**角度**で8方向を判定(0°=右、時計回り)
- 扇形の幅: **上下左右 各50°、斜め 各40°**(合計360°)。初期値で、実機で調整する
- 不感帯(中心付近): 半径の20%。一度入力した後は、不感帯の解除側を狭める(チラつき防止)
- ヒステリシス: 方向切替の境界で5°の余裕
- 判定領域は見た目より広く(余白24px)。`setPointerCapture` で、指が領域外に出ても入力を維持
- 指を離さず滑らせるだけで方向が変わる(`pointermove` で毎回再判定)
- 十字キーとボタンは別々の指として独立に追跡(同時押し可)

### 入力の堅牢性(確定)

- 決定系(A/B/MENU/SELECT)と方向は**ラッチ**: 押された事実を一定時間(120ms)保持し、次のフレームで必ず1回は処理する。古い押下は無効
- `pointercancel` / `lostpointercapture` / `blur` / `visibilitychange(hidden)` で**全入力を強制リセット**
- ブラウザ動作の抑止: `touch-action: none`、`user-select: none`、長押しメニュー・ダブルタップ拡大・ピンチ拡大・引っ張り更新の無効化
- 操作盤は `env(safe-area-inset-bottom)` の内側に置く
- 振動(ハプティクス): ボタン押下時に短く振動(Androidのみ。iOS Safariは非対応)。設定でON/OFFできる構造にする(設定画面は後回し)
- 押下中のボタン表示(色変化)を行う
- 開発用に `?debug=1` で入力状態(角度・方向・押下回数)を表示、`?touch=1` でPC上でも操作盤を表示

## 4. パーティ追従(MOTHER2/3方式)

- 最大4人
- 先頭だけが物理判定を持つ。後続は判定なしで、先頭の移動履歴をなぞる
- 履歴は時間ではなく**移動距離ごと**に記録。停止中は記録しない
- イベント中は後続を「待機」「重なって消える」などに切り替えられる口を用意
- 奥行きシーンでも同じ仕組みを使う(拡大縮小はキャラごとに計算)

## 5. シーン構成

| シーン | 役割 |
|---|---|
| BootScene | 素材読み込み・初期化 |
| TitleScene | タイトル・コンティニュー |
| FieldScene | タイルマップの俯瞰フィールド |
| ScenicScene | 高画質・奥行きあり(流れ星・ボス戦前・感動シーンなど、全体の数%)。歩ける範囲は多角形で定義、奥ほどキャラを縮小 |
| BattleScene | 戦闘。Field/Scenicは一時停止して状態を保持 |
| UIScene | 会話ウィンドウ・メニュー。Field/Scenic/Battle の上に重ねる共通UI |

- `GameState`(進行フラグ・所持品・パーティ・お金・現在地)は**シーンの外**に置き、**Phaser非依存の純粋なデータ**にする
- 「類似の状態は1つだけ持つ」: シーン内に状態の複製を持たない

## 6. イベント

- Tiledの配置物 / 起動条件 → イベントID → **JSONの命令列**を実行する小さなインタプリタ(EventRunner)
- 各命令は**終わるまで待つ**(会話が閉じるまで次へ進まない)
- 起動条件: 話しかける / エリアに入る / マップ読み込み時に自動 / フラグ条件
- 基本の挙動はMOTHER2/3・Undertaleに準拠
- 命令の語彙(初期案): `say` `choice` `if` `setFlag` `giveItem` `removeItem` `move` `wait` `playSound` `fade` `warp` `battle` `setParty`
- フラグは真偽値と数値の両方。命名は `分類.名前`(例: `story.met_old_man`)

## 7. 多言語・文字

- テキストは**ID参照**。実文は `ja.json` に置く(将来 `en.json` を追加するだけで拡張可能)
- 初期言語は日本語。**ひらがな・カタカナ中心**。漢字は必要時に追加できる前提
- プレイヤー名など変数は `{player}` の**差し込み方式**
- 禁則処理・自前改行・タイプライター表示を実装
- フォントはライセンス確認済みのドット風日本語フォントを使用(候補: DotGothic16 / SIL OFL)。描画はWebフォント方式 ※要確認

## 8. セーブ

| 項目 | 決定 |
|---|---|
| 形式 | 1つのJSON(`version`, `savedAt`, `playTimeSec`, `checksum`, `state`) |
| バージョン管理 | マイグレーション関数の配列(v1→v2→…)。セーブ形式を変えるたびに必ず追加 |
| スロット | 3スロット + オートセーブ1 |
| 保存タイミング | ゲーム内の特定手段(電話・セーブポイント)のみ。どこでも保存はしない |
| ストレージ | `IStorage` は**非同期(Promise)**。`get / set / remove`。初期実装は Web(localStorage または IndexedDB を内部で包む)。将来 Capacitor 実装に差し替え |
| 書き込み安全性 | 新データを別キーに書き、成功後に切り替え。1世代前も保持 |
| 通常のセーブ | **1ボタンで完了**。これが基本 |
| バックアップ(任意) | セーブ後に「バックアップコードを作る」ボタンを出す。押さなくてもセーブは完了済み |
| バックアップ主手段(B) | 圧縮+Base64の文字列。`navigator.share()` と コピー に対応。ハイフンで区切って表示、チェックサム付き、読み込み時は空白・ハイフン・改行を無視 |
| 補助(A) | JSONファイルの書き出し/読み込み(PC向け) |
| 予防(D) | `navigator.storage.persist()` を要求。ホーム画面への追加(PWA)を案内 |
| 見送り(C) | 短い「復活の呪文」。将来の遊び要素として検討 |

**フラグ番号のルール**: ビット列に詰める場合、フラグの番号は「追加のみ。並べ替え・削除は禁止」。

**要実機確認**: iOS Safari のストレージ削除条件(ホーム画面未追加時の挙動)。

## 9. 戦闘

- ターン制、**シンボルエンカウント**(敵がフィールドに見えていて、触れると開始)
- ローリングHPは**なし**。ただしHP表示は「現在値を返す関数」経由にし、後から追加できる構造にする
- 画面はMOTHER風(敵の正面表示。背景演出は後から)
- コマンド: たたかう / わざ / どうぐ / ぼうぎょ / にげる
- 最大4人。全員入力後、素早さ順に実行
- 経験値・レベルアップあり
- 敵・技・状態異常は**JSONで定義**
- 先制・自動勝利などは基本の戦闘ができてから追加

## 10. Tiled・命名規約

**レイヤー名**: `ground` / `decor_below` / `decor_above` / `collision` / `objects`

**オブジェクトのカスタムプロパティ**: `type`(`npc` `chest` `sign` `trigger` `warp` `enemy`)/ `id` / `eventId` / `spawnFlag`(任意)

**ファイル命名**: 小文字スネークケース、「種類_名前」の順
- `assets/maps/town_01.json`
- `assets/tilesets/town.png`
- `assets/sprites/npc_old_man.png`
- `assets/audio/bgm_town.m4a` / `se_confirm.m4a`(音声はm4a/mp3を基本。OGGはSafariで不安定)

**ID形式**: `種類.分類.名前`(例: `item.key.rusty` / `flag.story.met_old_man` / `text.npc.old_man.greet`)

**素材の出典**: `docs/ASSETS.md` に作者・ライセンス・URLを記録(自作は「自作」)

## 11. コード規約

- `strict: true`、`any` 禁止
- マジックナンバーは `src/config/` に置く
- 深い継承を避け、浅い継承 + 小さなシステム/コンポーネントに分ける
- データ(マップ・会話・アイテム・敵・技)はJSON、コードと分離
